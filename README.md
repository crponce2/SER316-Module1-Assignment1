# **Number Guessing Game** 



This is a Java number-guessing game. It uses branches to demonstrate Advanced Branching, Rebasing, Squashing, and Cherry-Picking. 



## Branch Descriptions

**main:** This contains the initial version of the number guessing game. 

**dev:** Adds an encouraging message for players. 

**feature1:** Adds an option to quit, play again, and improved messages. 

**feature2:** Adds a limit to how many guesses a player can make as well as game over condition. 

**feature3:** Adds hint to help player guess the number. 

**hotfix:** Fixes the randomInt to properly include max value in range. 

**documentation:** Used for the README and notes about the assignment
